# 【水下的牌】与玩家身份牌位置分隔线

> **Status**: complete · **Priority**: medium · **Created**: 2026-05-24

## Overview

当前对局界面同时展示【水下的牌】与各玩家身份牌。如果两组牌在视觉上靠得较近，玩家可能误以为它们属于同一区域，影响选择目标时对“水下位置”和“玩家位置”的判断。

本规格要求在【水下的牌】区域和玩家身份牌区域之间增加一条清晰但不喧宾夺主的分隔线，用于表达两类牌处于不同位置。该改动只影响视觉层级与可读性，不改变卡牌内容、点击规则、身份可见性、动画或结算逻辑。

## Design

- 在【水下的牌】区域下方或玩家身份牌区域上方加入横向分隔线，使两组卡牌在桌面端和移动端都能被明确区分。
- 分隔线应使用低对比但可见的样式，例如半透明边框、渐变线或主题色弱化线条，避免抢占卡牌本身的视觉权重。
- 分隔线应跟随现有布局宽度自适应，不引入横向滚动，不破坏卡牌网格间距。
- 分隔线不得影响卡牌点击区域；玩家身份牌和水下牌的可交互状态、选中态、翻牌动画必须保持不变。
- 结算阶段仍应保留该位置区分，避免最终身份牌与最终水下牌混淆。

- 分隔线样式放在 `src/client/styles/main.css`，使用低对比渐变线和 `pointer-events: none`，不影响卡牌点击。
