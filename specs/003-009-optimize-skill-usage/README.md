# 优化技能使用方式

## Overview

当前技能阶段中，点击目标卡牌会直接提交行动或触发翻牌，容易让玩家因误触而暴露信息或交换错误目标。需要将技能交互改为“点击选中 → 确认使用”：点击卡牌时只更新本地选中状态，卡牌暂时不翻转、不揭示身份、不执行交换；只有按下确认按钮后才真正发动技能。

对于允许不发动的可选技能，玩家未选择任何目标时，确认按钮文案应显示为“不使用技能”，点击后显式跳过该技能。

## Design

- 技能阶段统一使用“可点击目标卡牌 + 确认按钮”的交互模型，替代点击卡牌立即提交行动。
- 点击可选目标卡牌时：
  - 卡牌保持当前朝向；若原本面朝下，未确认前不得翻转或显示身份。
  - 仅显示选中反馈：卡牌周围出现类似荧光的边框、外发光或轻微呼吸动画。
  - 再次点击已选中卡牌可取消选中；目标数量不得超过当前技能允许上限。
- 确认按钮行为：
  - 已选目标满足技能要求时，按钮显示“确认使用技能”，点击后才发送对应技能行动，随后按服务端结果执行翻牌、揭示或交换展示。
  - 狼人、预言家、强盗在空选时按钮显示“不使用技能”，点击后显式跳过当前技能，不触发翻牌或交换。
  - 捣蛋鬼、水鬼属于必选技能，空选或目标不足时确认按钮禁用，并用中文提示需要选择足够目标；不得显示“不使用技能”。
- 各身份目标规则保持不变：
  - 狼人：选中 1 张水下牌后可确认查看。
  - 预言家：选择 1 名玩家，或选择 2 张水下牌；首个选中目标锁定本次模式，满足对应数量后才可确认。
  - 强盗：选中 1 名其他玩家后可确认查看并交换。
  - 捣蛋鬼：选中 2 名其他玩家后可确认交换，不揭示身份。
  - 水鬼：选中 1 张水下牌后可确认交换，不揭示身份。
- 非行动玩家、非当前身份阶段、不可作为目标的卡牌仍不可点击，也不应展示可提交的确认按钮。
- 显式跳过可复用现有“可选技能未发动”的规则语义，但必须由玩家点击“不使用技能”立即完成当前技能选择，而不是等待倒计时结束。

## Notes

- 该变更是交互语义调整：翻牌动画仍应保留，但触发时机从“点击卡牌”后移到“确认使用技能并收到结果”后。
- “不使用技能”只适用于允许跳过的可选技能；必选技能仍依赖玩家确认有效目标或服务端超时自动处理。
- 实施中扩展了客户端 `SelectionState`，为狼人、预言家玩家目标、强盗和水鬼增加待确认目标字段；卡牌点击只更新本地选中状态，确认按钮负责发送 `action:*`。
- 新增 `action:skip` Socket 事件与 `skipOptionalRoleAction` 引擎路径，用空目标 action 标记狼人/预言家/强盗主动不使用技能，避免等待倒计时。
- `projectPrivateRoomView` 在当前玩家已完成对应身份行动后不再下发 `currentEligibleAction`，防止重连后重复提交；界面显示“身份行动已提交”。
- 选中态样式改为蓝绿色荧光外发光和呼吸动画，仍保留 `.clickable` 用于再次点击取消。
- 验证通过：`npm test -- --run`、`npm run build`、`npm run test:e2e`。
