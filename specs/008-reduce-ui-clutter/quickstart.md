# Quickstart: 精简界面无意义UI、减少纵向内容展

**Feature**: 008-reduce-ui-clutter | **Date**: 2026-05-24

## 前置条件

- Node.js 20+
- npm install
- 当前代码库已通过所有 83 个测试

## 变更范围

纯前端变更：`src/client/views/game.ts`（HTML 模板微调）+ `src/client/styles/main.css`（CSS 尺寸调整）。无后端变更。

## 快速验证

### 1. 启动服务

```bash
npm run dev
```

浏览器打开 `http://localhost:5173`（三个窗口模拟三名玩家）。

### 2. 验证房间号移除

1. 创建房间，三名玩家加入，开始游戏
2. **验证**: 游戏界面顶部不再显示"房间 XXXXXX"
3. 大厅界面仍显示房间码（用于邀请），但样式更紧凑

### 3. 验证阶段标识缩小

1. 观察各阶段切换时的阶段标识
2. **验证**: 阶段标题（如"闭眼准备"）字体明显小于变更前，不再占据大量垂直空间
3. **验证**: 阶段名称 + 倒计时 + 行动提示在移动端首屏可见

### 4. 验证玩家身份牌横向排列

1. 查看三名玩家的卡牌区域
2. **验证**: 每张卡牌下方显示昵称和徽章（而非上方），昵称作为卡牌的标签
3. **验证**: 三张卡牌水平并排（通过 `.players-grid` 的 3 列网格）

### 5. 验证卡牌尺寸缩小

1. 打开浏览器 DevTools，检查 `.card` 元素
2. **桌面端验证**: 卡牌宽度约 100px，高度约 150px
3. **移动端验证**: 使用 DevTools 设备模拟（iPhone SE 375px 宽度）
   - 卡牌宽度在 80–96px 范围
   - 6 张卡牌（3 水下 + 3 玩家）+ 阶段标识 + 倒计时在首屏内无需滚动可见
4. **验证**: 身份文字（如"狼人"、"预言家"）在缩小后仍清晰可读

### 6. 验证交互功能正常

1. 在狼人/预言家/强盗/捣蛋鬼/水鬼行动阶段，点击可点击的卡牌
2. **验证**: 点击交互正常（翻转动画、选中高亮、悬停效果）
3. **验证**: 触摸设备上可点击区域足够大（≥ 44×44px）

### 7. 运行测试

```bash
npm test
```

**预期**: 所有 83 个测试继续通过。E2E 测试如有截图对比可能需要更新基准。
